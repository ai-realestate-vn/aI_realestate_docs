# #️⃣ **1.3 — RESPONSE LAYER (NLG + PACKAGING + STM UPDATE)**

**Mục tiêu:**
Nhận plan từ Decision Layer → **tạo câu trả lời tự nhiên** + **gọi API** (nếu cần) + **đóng gói data** + **cập nhật STM**.

**Input:**

```json
{
  "action": "ACTION_NAME",
  "payload": { ... }
}
```

**Output (trả về cho FE + STM):**

```json
{
  "messages": [...],
  "apartments": [...],
  "session_update": {...}
}
```

---

# ## 1. Nhiệm vụ chính của Response Layer

1️⃣ Nhận action từ 1.2
2️⃣ Gọi API tương ứng (Qdrant search / DB / Booking / RAG)
3️⃣ Sinh câu trả lời (NLG Template)
4️⃣ Đóng gói kết quả thành JSON chuẩn (messages + data)
5️⃣ Cập nhật STM (slots, dialog_state, episodic summary)

Response Layer **không quyết định logic** → chỉ thực thi theo action.

---

# ## 2. Action → Response Mapping (Chuẩn để lập trình)

Dưới đây là toàn bộ action bot có thể nhận được từ 1.2 và cách trả về response.

---

## ### **1) ASK_SLOT (hỏi bổ sung thông tin)**

**Input từ 1.2:**

```json
{
  "action": "ASK_SLOT",
  "payload": { "slot": "dien_tich" }
}
```

**NLG template (ví dụ):**

> Anh/chị muốn diện tích tối thiểu khoảng bao nhiêu m² ạ?

**Output:**

```json
{
  "messages": [
    {
      "type": "text",
      "content": "Anh/chị muốn diện tích tối thiểu khoảng bao nhiêu m² ạ?"
    }
  ],
  "apartments": [],
  "session_update": {
    "dialog_state": "COLLECTING"
  }
}
```

---

## ### **2) SEARCH_LISTINGS (gọi Qdrant tìm căn hộ)**

**Input từ 1.2:**

```json
{
  "action": "SEARCH_LISTINGS",
  "payload": { "filters": { ... } }
}
```

**Luồng thực thi:**

- Gọi API Qdrant với filters
- Nếu có kết quả → trả về **PRESENT_RESULTS**
- Nếu không → trả về **NO_RESULT**

(1.3 chỉ thực thi; logic quyết định ở 1.2)

---

### **2.1 Trường hợp có kết quả → PRESENT_RESULTS**

**NLG template:**

> Em tìm được {{N}} căn phù hợp với yêu cầu của anh/chị. Anh/chị muốn xem chi tiết căn nào ạ?

**Output:**

```json
{
  "messages": [
    { "type": "text", "content": "Em tìm được 3 căn phù hợp ở Quận 7 dưới 3 tỷ." }
  ],
  "apartments": [
    { "ma_can": "...", "gia_ban": 2850000000, ... },
    { "ma_can": "...", ... }
  ],
  "session_update": {
    "dialog_state": "PRESENTING",
    "slots": { ...updated slots... }
  }
}
```

---

### **2.2 Trường hợp không có kết quả → NO_RESULT**

**NLG template:**

> Hiện chưa có căn nào đúng tiêu chí. Anh/chị muốn tăng ngân sách hay đổi khu vực không ạ?

**Output:**

```json
{
  "messages": [
    {
      "type": "text",
      "content": "Hiện chưa có căn nào đúng tiêu chí. Anh/chị muốn tăng ngân sách hay đổi khu vực không ạ?"
    }
  ],
  "apartments": [],
  "session_update": {
    "dialog_state": "COLLECTING"
  }
}
```

---

## ### **3) PRESENT_RESULTS (hiển thị danh sách căn)**

(Trường hợp 1.2 đã yêu cầu trình bày data)

**NLG template:**

> Đây là một vài căn em lọc được cho anh/chị:

**Output:**

```json
{
  "messages": [
    {
      "type": "text",
      "content": "• Sunrise Riverside – 2PN – 2.85 tỷ – 70m²\n• Eco Green – 2PN – 2.75 tỷ – 68m²\n• Mizuki Park – 2PN – 2.9 tỷ – 72m²"
    }
  ],
  "apartments": [...3 căn...],
  "session_update": {
    "dialog_state": "PRESENTING"
  }
}
```

---

## ### **4) SHOW_DETAILS**

**Input:**

```json
{
  "action": "SHOW_DETAILS",
  "payload": { "ma_can_ho": "A1205" }
}
```

**Luồng:**

- Tạo câu chi tiết → gửi về FE

**Output:**

```json

  "messages": [
    {
      "type": "text",
      "content": "Căn A1205 có 2PN – 70m² – hướng Đông – giá 2.85 tỷ..."
    }
  ],
  "apartments": [
    { "ma_can": "A1205", "dien_tich": 70, "gia_ban": 2850000000, ... }
  ],
  "session_update": {
    "dialog_state": "DETAIL",
    "last_viewed": "A1205"
  }
}
```

# ## 3. Output Format Tổng Hợp

Tất cả action đều trả về format chuẩn:

```json
{
  "messages": [...],
  "apartments": [...],
  "session_update": {
    "dialog_state": "...",
    "slots": {...},
    "episodic_summary": "..."
  }
}
```

---

# ## 4. STM Update (Nguyên tắc)

- **slots** → cập nhật theo dữ liệu mới từ câu trả lời
- **dialog_state** →

  - ASK_SLOT → COLLECTING
  - PRESENT_RESULTS → PRESENTING
  - SHOW_DETAILS → DETAIL
  - BOOKED → BOOKED

- **episodic_summary** → tóm tắt lượt hiện tại để làm context cho lượt sau

---

# ## 5. Tóm tắt dễ hiểu

| Action           | Response          | API                 | STM Update |
| ---------------- | ----------------- | ------------------- | ---------- |
| ASK_SLOT         | Hỏi thêm          | ❌                  | COLLECTING |
| SEARCH_LISTINGS  | Gọi Qdrant        | ✔️                  | PRESENTING |
| PRESENT_RESULTS  | Hiển thị 3 căn    | ❌ (data từ search) | PRESENTING |
| SHOW_DETAILS     | Chi tiết căn      | ✔️                  | DETAIL     |
| BOOK_APPOINTMENT | Đặt lịch          | ✔️                  | BOOKED     |
| NO_RESULT        | Gợi ý thêm        | ❌                  | COLLECTING |
| RAG_LOOKUP       | Trả lời dựa KB    | ✔️                  | ANSWERED   |
| ASK_REPHRASE     | Yêu cầu mô tả lại | ❌                  | COLLECTING |
| SMALLTALK        | Chào hỏi          | ❌                  | IDLE       |
