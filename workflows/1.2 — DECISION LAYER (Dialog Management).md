# 1.2 — DECISION LAYER (Dialog Management)

**Mục tiêu:**
Dựa vào intent + slots + STM từ 1.1 để quyết định hành động (action) và payload của action.

**Output:**

```json
{
  "action": "ACTION_NAME",
  "payload": { ... }
}
```

File này không sinh câu trả lời, chỉ trả lệnh để 1.3 thực thi.

## 1. Luồng xử lý (Decision Flow)

### Step 1 — Nhận intent từ 1.1

5 intent chính:

1. search_apartment
2. show_details
3. book_appointment
4. ask_question
5. general_chat

→ Mỗi intent có slot bắt buộc và hành động riêng.

### Step 2 — Kiểm tra slot bắt buộc

Thiếu slot → ASK_SLOT
Đủ slot → thực hiện action chính

### Step 3 — Xử lý tuỳ intent

Mapping intent → action sẽ được mô tả ở phần dưới.

## 2. Slot Requirement (các slot bắt buộc theo intent)

### 1) search_apartment

Cần ít nhất:

- `khu_vuc` hoặc `du_an`
- `gia_ban` (min/max)
- `so_phong_ngu`

Thiếu bất kỳ slot bắt buộc nào → ASK_SLOT

### 2) show_details

- `ma_can_ho`

Nếu thiếu → ASK_SLOT: ma_can_ho

### 3) book_appointment

- `ma_can_ho`
- `thoi_gian`
- `sdt`

Thiếu bất kỳ slot bắt buộc nào → ASK_SLOT

### 4) ask_question

- `chu_de` (giá, pháp lý, tiện ích, vị trí…)

Thiếu chu_de → ASK_SLOT

### 5) general_chat

- Không yêu cầu slot.

## 3. Slot-Filling Logic (Nếu thiếu → hỏi thêm)

Nếu thiếu slot bắt buộc → gửi action: ASK_SLOT

**Ví dụ:**

Payload:

```json
{
  "action": "ASK_SLOT",
  "payload": { "slot": "<slot_name>" }
}
```

Ví dụ payload đầu vào:

```json
{
  "so_phong_ngu": 2,
  "gia_ban": { "max": 3000000000 }
}
```

-> Thiếu khu_vuc → action: ASK_SLOT

```json
{
  "action": "ASK_SLOT",
  "payload": { "slot": "khu_vuc" }
}
```

## 4. Khi nào bot được phép SEARCH?

Bot chỉ được search khi tất cả slot bắt buộc đã đủ.

**Ví dụ đã có:**

- `khu_vuc` = quận 7
- `so_phong_ngu` = 2
- `gia_ban.max` = 3 tỷ
- `dien_tich.min` = 70

thực hiện search

```json
{
  "action": "SEARCH_LISTINGS",
  "payload": {
    "filters": {
      "so_phong_ngu": { "min": 2, "max": 2 },
      "gia_ban": { "max": 3000000000 },
      "huong": ["Đông"],
      "dien_tich": { "min": 70 },
      "khu_vuc": "quận 7"
    }
  }
}
```

## 5. Xử lý kết quả khi SEARCH

### Nếu có kết quả

Action: PRESENT_RESULTS

```json
{ "action": "PRESENT_RESULTS" }
```

### Nếu không có kết quả

Action: NO_RESULT

```json
{
  "action": "NO_RESULT",
  "payload": {
    "suggestions": [
      "Tăng ngân sách",
      "Đổi khu vực",
      "Giảm tiêu chí diện tích"
    ]
  }
}
```

## 6. Repair & Clarify (khi câu mơ hồ)

Nếu:

- NLU confidence < 0.70
- Người dùng nói mơ hồ
- Thông tin mâu thuẫn

→ Yêu cầu người dùng nói rõ hơn:

```json
{ "action": "ASK_REPHRASE" }
```

## 7. Intent → Action Mapping (rõ ràng)

### Intent: search_apartment

| Điều kiện           | Action            | Payload                    |
| ------------------- | ----------------- | -------------------------- |
| Thiếu slot bắt buộc | `ASK_SLOT`        | { "slot": "<slot_name>" }  |
| Đủ slot             | `SEARCH_LISTINGS` | { "filters": { ... } }     |
| Có kết quả          | `PRESENT_RESULTS` | { "results": [ ... ] }     |
| Không có kết quả    | `NO_RESULT`       | { "suggestions": [ ... ] } |

### Intent: show_details

| Điều kiện       | Action         | Payload                 |
| --------------- | -------------- | ----------------------- |
| Thiếu ma_can_ho | `ASK_SLOT`     | { "slot": "ma_can_ho" } |
| Có ma_can_ho    | `SHOW_DETAILS` | { "ma_can_ho": "..." }  |

### Intent: book_appointment

| Điều kiện           | Action             | Payload                                                  |
| ------------------- | ------------------ | -------------------------------------------------------- |
| Thiếu slot bắt buộc | `ASK_SLOT`         | { "slot": "<slot_name>" }                                |
| Đủ slot             | `BOOK_APPOINTMENT` | { "ma_can_ho": "...", "thoi_gian": "...", "sdt": "..." } |

### Intent: ask_question

| Điều kiện           | Action       | Payload                                    |
| ------------------- | ------------ | ------------------------------------------ |
| Thiếu slot bắt buộc | `ASK_SLOT`   | { "slot": "<slot_name>" }                  |
| Đủ slot             | `RAG_LOOKUP` | { "topic": "gia_ban", "ma_can_ho": "..." } |

### Intent: general_chat

-> luôn là

```json
{ "action": "SMALLTALK" }
```

## 8. Tóm tắt dễ hiểu (bảng)

| Trường hợp              | Action             | Payload                                                  |
| ----------------------- | ------------------ | -------------------------------------------------------- |
| Thiếu slot bắt buộc     | `ASK_SLOT`         | { "slot": "<slot_name>" }                                |
| Đủ slot → tìm căn       | `SEARCH_LISTINGS`  | { "filters": { ... } }                                   |
| Có kết quả              | `PRESENT_RESULTS`  | { "results": [ ... ] }                                   |
| Không có kết quả        | `NO_RESULT`        | { "suggestions": [ ... ] }                               |
| Xem chi tiết căn        | `SHOW_DETAILS`     | { "ma_can_ho": "..." }                                   |
| Đặt lịch xem nhà        | `BOOK_APPOINTMENT` | { "ma_can_ho": "...", "thoi_gian": "...", "sdt": "..." } |
| Hỏi kiến thức dự án/căn | `RAG_LOOKUP`       | { "topic": "gia_ban", "ma_can_ho": "..." }               |
| Chat xã giao            | `SMALLTALK`        |
